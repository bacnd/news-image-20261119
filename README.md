Every headline is drawn from reports of that day, and every word on the page is rendered in code so the text stays crisp.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. It uses only the Node 22 standard library and no network, so every run writes the same bytes.
